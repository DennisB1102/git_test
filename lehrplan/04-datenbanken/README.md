# Modul 4 – Datenbanken & SQL

**Ziel:** Du verstehst relationale Datenbanken, schreibst SQL sicher von Hand, entwirfst sinnvolle Tabellenstrukturen und greifst mit PDO aus PHP darauf zu.

**Geschätzter Aufwand:** 25–40 Stunden

**Warum SQL lernen, wenn Laravel Eloquent hat?** Eloquent erzeugt SQL für dich. Wenn deine Anwendung langsam ist oder falsche Daten liefert, musst du das erzeugte SQL lesen und verstehen können. Und in Vorstellungsgesprächen wird SQL fast immer abgefragt.
