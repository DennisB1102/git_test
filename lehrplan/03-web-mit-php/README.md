# Modul 3 – Web mit reinem PHP

**Ziel:** Du baust dynamische Webseiten mit PHP – noch ohne Framework. Du verstehst, wie Formulare, Sessions und Routing funktionieren und welche Sicherheitslücken lauern.

**Geschätzter Aufwand:** 25–40 Stunden

**Warum ohne Framework?** Laravel nimmt dir all das später ab. Wenn du es aber einmal selbst gebaut hast, verstehst du, *was* Laravel für dich tut – und warum. Das Modul ist bewusst kurz gehalten: Ziel ist Verständnis, nicht ein eigenes Framework.
