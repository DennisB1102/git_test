# 🧭 Geführtes Projekt: Laravel-Tutorial

## Einführung

Bevor du ein eigenes Projekt ohne Anleitung baust, arbeitest du einmal ein offizielles, geführtes Tutorial durch. Es verbindet alle Themen dieses Moduls zu einer kleinen, vollständigen Anwendung.

## Aufgaben

1. Arbeite das offizielle Einsteiger-Tutorial von Laravel durch: **[Laravel Learn](https://laravel.com/learn)** (dort findest du u. a. einen Bootcamp-Kurs, in dem eine kleine Social-Media-App gebaut wird). Falls sich Adresse oder Aufbau geändert haben, findest du das aktuelle Tutorial über die Laravel-Startseite.
2. **Wichtig:** Tippe den Code selbst ab, statt ihn zu kopieren. Und bevor du einen Schritt ausführst: Überlege kurz, was er bewirken wird.
3. Erweitere die fertige App um ein Feature, das im Tutorial nicht vorkommt (z. B. Likes oder ein Profilbild).
