# Modul 5 – Laravel-Grundlagen

**Ziel:** Du baust vollständige Webanwendungen mit Laravel: Routing, Controller, Blade-Templates, Datenbank mit Eloquent, Formulare mit Validierung und Benutzer-Authentifizierung.

**Geschätzter Aufwand:** 50–70 Stunden

**Hauptquelle ist die [offizielle Laravel-Dokumentation](https://laravel.com/docs).** Sie ist hervorragend geschrieben und immer aktuell. Laravel erscheint jährlich in einer neuen Hauptversion – achte bei Tutorials, Blogartikeln und KI-Antworten immer darauf, für welche Version sie geschrieben wurden.
