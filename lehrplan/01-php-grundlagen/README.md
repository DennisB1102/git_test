# Modul 1 – PHP-Grundlagen

**Ziel:** Du beherrschst die Sprache PHP selbst: Variablen, Typen, Kontrollstrukturen, Funktionen, Arrays, Strings und den Umgang mit Fehlern. Alles zunächst im Terminal – ohne Browser, ohne Framework.

**Geschätzter Aufwand:** 40–60 Stunden

**Warum erst ohne Laravel?** Laravel ist PHP. Wer PHP nicht versteht, versteht Laravel-Fehlermeldungen nicht und kann nur Tutorials nachbauen. Das ist wie Medikamente geben, ohne die Pharmakologie zu kennen.
